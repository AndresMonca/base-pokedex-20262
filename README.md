# WikiDex · Pokédex React

**Autor:** Edwin Andres Montaño Castañeda

**GitHub Pages:** [Link Pages](https://andresmonca.github.io/base-pokedex-20262/)

WikiDex es una Pokédex interactiva desarrollada en React que permite explorar Pokémon, consultar información detallada, gestionar una colección de capturas, visualizar formas, evoluciones, estadísticas y movimientos, y navegar por una interfaz inspirada en el universo Pokémon. El proyecto está diseñado para adaptarse a distintos tamaños de pantalla, mantener una experiencia visual coherente y conservar el progreso del usuario mediante almacenamiento local.

[📄 Ver informe detallado de la migración a React](./docs/informe-migracion-react.md)
